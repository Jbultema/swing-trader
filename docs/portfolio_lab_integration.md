# Portfolio Lab Integration And Schedule Correction

Swing Trader owns entry, persistence, holding and exit rules. The frozen ETF champion remains
monthly twelve-month momentum; the faster rejected model is exported only as a diagnostic.
The new persistent-recovery arm is research-only and does not alter the champion.

```sh
poetry run python -m swing_trader.portfolio_export --output ../portfolio-lab/data/bundles/RUN/swing-trader
```

Native next-open accounting remains separate from Portfolio Lab's self-financing next-close
replay. A causal monthly scheduling correction uses planned NYSE regular holidays instead of
the final captured observation. It handles a Good-Friday month end without future prices and
does not anticipate unexpected emergency closures. Regenerate native research evidence before
comparing implementation identities; old immutable paper lineages must not be rewritten.

Fundamental Event Trader consumes hash-verified SEC sidecar artifacts via its importer. Filing
metadata remains context only here; it does not become a new directional ranking input. Neither
project imports the other's strategy implementation. No operating stock-shadow policy is changed.
